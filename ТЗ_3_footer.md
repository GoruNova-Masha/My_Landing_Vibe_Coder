## Задача
Реализовать раздел «Контакты» и подвал (Footer) на стеке Next.js (App Router) + TypeScript + Tailwind CSS. Стиль: «Монохромный техно» (тёмный фон, серые полупрозрачные элементы, циановые акценты). Требования:
- Вариант Б: в футере — только кнопка «Политика конфиденциальности». При клике открывается модальное окно с полным текстом.
- Перевод всех текстов на русский язык.
- Структура по референсу: слева — контакты, справа — форма.
- Якорный переход из хедера (кнопка «Поработаем вместе» → #contacts).
- Простая валидация формы на клиенте.
- Обработка отправки данных через Formspree.
- Адаптивность под мобильные и десктоп.

## Логика модального окна
- Используй React `useState` для управления видимостью окна (`isModalOpen`).
- При клике на кнопку в футере: `setIsModalOpen(true)`.
- При клике на крестик или затемнённый фон: `setIsModalOpen(false)`.
- Убедись, что при открытии модального окна скролл страницы блокируется (можно через `document.body.style.overflow = 'hidden'` и обратно).

## Логика валидации и отправки (Formspree)
- Используй React `useState` для хранения значений полей и ошибок.
- Валидация при сабмите (onSubmit):
  - Если поле «Имя» пустое → ошибка: «Пожалуйста, укажите ваше имя».
  - Если поле «Email» пустое → ошибка: «Пожалуйста, укажите ваш email».
  - Если поле «Сообщение» пустое → ошибка: «Пожалуйста, напишите сообщение».
  - Если email невалидный (простая проверка на наличие @) → ошибка: «Пожалуйста, укажите корректный email».
- Сообщения об ошибках выводи под соответствующим полем красным цветом (`text-red-400/70`, `text-sm`, `mt-1`).
- Поля с ошибкой должны подсвечиваться красной рамкой (`border-red-500`).
- При успешной валидации отправляй данные на Formspree.
- URL эндпоинта: `https://formspree.io/f/ВАШ_ID_ФОРМЫ` (заменить на реальный ID из Formspree).
- Данные отправляй в формате JSON.
- После успешной отправки:
  - Покажи сообщение об успехе над кнопкой: «Спасибо! Ваше сообщение отправлено. Мы свяжемся с вами в ближайшее время.» (`text-cyan-300`, `text-sm`, `mb-4`).
  - Очисти форму.
  - Заблокируй кнопку на время запроса (текст: «Отправляется...»).
- Обработка ошибок сети: если Formspree вернул ошибку, покажи сообщение: «Произошла ошибка при отправке. Попробуйте позже.» (`text-red-400`, `text-sm`, `mb-4`).

## Стилистика и визуал
- Фон раздела: `bg-[#0b0b0b]`.
- Акценты: циановые оттенки (`cyan-300`, `cyan-400`) только для интерактивных элементов.
- Минимализм: никаких лишних декоративных элементов.

## Адаптивность и UX
- Mobile: контакты и форма друг под другом, отступы сохраняют читаемость.
- Desktop: 2 колонки, форма выровнена по верхнему краю с контактами.
- На мобильных: поля ввода занимают всю ширину, кнопка — на всю ширину.
- В подвале: на мобильных все колонки друг под другом, на десктопе — в 2 колонки.
- Модальное окно: на мобильных — с отступами по бокам, на десктопе — центрировано.

## Критерии приёмки
- В футере нет громоздкого текста — только кнопка «Политика конфиденциальности».
- При клике на кнопку открывается модальное окно с полным текстом политики.
- В модальном окне есть кнопка «Написать нам» со ссылкой на форму контактов.
- Контакты слева, форма справа (на десктопе).
- Кнопка «Поработаем вместе» в хедере плавно прокручивает к разделу «Контакты».
- Валидация на клиенте работает корректно, сообщения об ошибках отображаются под полями.
- При успешной отправке показывается сообщение об успехе, форма очищается.
- Кнопка блокируется во время отправки.
- Дизайн соответствует теме: тёмный фон, эффект стекла, циановые акценты.
- Нет ошибок в консоли, верстка не «едет» на мобильных.
- Используются семантические теги (`section`, `h2`, `p`, `form`, `label`, `input`, `button`, `footer`).

## Важные ограничения
- Не меняй тексты заголовков, подзаголовков и полей формы.
- Не добавляй лишние поля в форму.
- Не используй яркие цвета вне неоновой палитры.
- Не убирай эффект стекла и полупрозрачности у блоков контактов.
- Обязательно замени `ВАШ_ID_ФОРМЫ` в URL на реальный ID из Formspree.
