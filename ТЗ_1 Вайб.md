# Задача: добавить фиксированную навигационную панель (Navbar) на лендинг

## Контекст
Проект: лендинг Марии Горюновой (вайб-кодер).  
Стек: Next.js (App Router), TypeScript, Tailwind CSS.  
Текущий вид: тёмный фон, неоновые акценты, минимализм.  
Цель: вернуть горизонтальную навигацию «Обо мне / Услуги / Портфолио / Поработаем вместе» в верхней части экрана.

## Требования к реализации

1. Создать компонент `components/Navbar.tsx`:
   - Позиционирование: `fixed top-0 left-0 w-full z-50`.
   - Контейнер: `container mx-auto px-6 py-5 flex justify-between items-center`.
   - Логотип: текст «МАРИЯ ГОРЮНОВА», белый, `font-bold text-xl tracking-wide uppercase`.
   - Меню: горизонтальное, `flex gap-8 items-center`.
   - Пункты меню:
     - «Обо мне» → ссылка `#about`
     - «Услуги» → ссылка `#services`
     - «Портфолио» → ссылка `#portfolio`
     - Кнопка «Поработаем вместе» → ссылка `#contact`, стиль: полупрозрачный белый фон (`bg-white/5`), обводка (`border border-white/30`), скругления (`rounded-full`), при наведении — `bg-white/10`.
   - При наведении на текстовые ссылки менять цвет на `cyan-400` с плавным переходом (`transition-colors duration-300`).
   - Использовать `'use client'` и `Link` из `next/link`.

2. Подключить `Navbar` в `app/layout.tsx`:
   - Импортировать: `import Navbar from '@/components/Navbar';`.
   - Рендерить перед `{children}` внутри `<body>`.
   - Убедиться, что у `body` нет лишних отступов, мешающих `fixed` панели.

3. Добавить якоря в `app/page.tsx`:
   - Обернуть секции в `<section>` с `id`: `#about`, `#services`, `#portfolio`, `#contact`.
   - Добавить отступы сверху, чтобы при переходе по якорю панель не перекрывала заголовок: `pt-28 pb-16`.

4. Проверить конфигурацию Tailwind:
   - В `tailwind.config.js` в поле `content` должны быть пути к `app/**/*`, `components/**/*`, `pages/**/*`.
   - В `globals.css` должны быть директивы `@tailwind base; @tailwind components; @tailwind utilities;`.

5. Адаптивность и нюансы:
   - На экранах меньше 768px меню может сжиматься; бургер‑меню не требуется на этом этапе.
   - Если проект на JS (не TS) — убрать `'use client'` и типизации.
   - После правок перезапустить сервер (`npm run dev`) и проверить в браузере.

## Критерии приёмки
- Панель видна в верхней части экрана и остаётся при прокрутке.
- Ссылки ведут к соответствующим секциям (плавный скролл).
- При наведении пункты меню подсвечиваются неоновым цианом, кнопка меняет прозрачность.
- Нет ошибок в консоли браузера и в терминале.
- Дизайн соответствует стилю лендинга (тёмный фон, неоновые акценты).

## Дополнительные пожелания
- Если в проекте уже есть компонент `Navbar` — обновить его под это ТЗ, а не создавать новый.
- Если какие‑то файлы отсутствуют (например, `components/` нет) — создать нужную структуру папок.
