# Промпт для Cursor: создание сайта‑портфолио вайб‑кодера Maria Krause

## Задача
Сгенерировать полный код для современного, стильного сайта‑портфолио начинающего вайб‑кодера **Maria Krause**. Сайт должен сочетать профессионализм и лёгкую неформальность, подчёркивать «вайб» через дизайн и интерактивность.

## Контекст проекта

* **Целевая аудитория:** стартапы, малые бизнесы, HR‑специалисты IT‑компаний, коллеги‑разработчики.
* **Цель сайта:** продемонстрировать навыки, представить услуги, показать подход к работе, обеспечить удобные способы связи.
* **Стиль:** современный минимализм с элементами глассморфизма/неоморфизма, плавные углы, мягкие тени.
* **Настроение:** «код с атмосферой», дружелюбно, но профессионально.

## Технические требования

* **Фронтенд:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+).
* **Фреймворк:** React (с Vite для сборки).
* **Библиотеки:**
  * GSAP (для анимаций);
  * React Router (для навигации, если многостраничный вариант).
* **Хостинг:** совместимость с Netlify/Vercel (статический деплой).
* **Адаптивность:** полная поддержка мобильных, планшетов, десктопов.

## Дизайн‑спецификации

* **Цветовая палитра:**

  * элементы: полупрозрачные блоки с `backdrop-filter` (глассморфизм).
* **Шрифты:** Inter (заголовки), Roboto (текст) — подключить через Google Fonts.
* **Анимации:**
  * плавные переходы (`transition: all 0.3s ease`);

  * параллакс‑эффект на главной;
