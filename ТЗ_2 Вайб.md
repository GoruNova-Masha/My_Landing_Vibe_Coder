## Задача
Реализовать раздел «Портфолио» на стеке Next.js (App Router) + TypeScript + Tailwind CSS. Стиль: «Монохромный техно» (тёмный фон, серые полупрозрачные элементы, неоновые акценты). Требования:
- Без превью‑картинок (скриншотов).
- Единый неоновый стиль кнопок.
- Неоновая рамка у каждой карточки.
- Вся карточка — кликабельная область.
- Простая анимация появления карточек при скролле.
- Оптимизированная логика для мобильных устройств (тап = переход, без лишних эффектов).

3. Заголовок проекта:

4. Описание:

## Стилистика и визуал
- Фон раздела: `bg-[#0b0b0b]` или `bg-[#0f0f0f]` (подбери под общий `body`).
- Карточка (обёртка `a`):
  - Базовые классы: `group block p-6 rounded-xl border border-slate-800/30 transition-all duration-300`.
  - Ховер‑эффект (Desktop): `hover:border-cyan-400/60 hover:shadow-[0_0_24px_rgba(85,239,255,0.15)]`.
  - Важно: вся карточка — кликабельная область, ведёт на указанный URL.
- Акценты: неоновые оттенки (`cyan-300`, `cyan-400`) только для интерактивных элементов.

## Анимация появления при скролле
- Используй библиотеку `framer-motion` (если её нет в проекте — добавь в зависимости: `npm install framer-motion`).
- Каждая карточка должна иметь простую анимацию появления:
  - Начальное состояние: `opacity-0 translate-y-12`.
  - Конечное состояние: `opacity-100 translate-y-0`.
  - Длительность: `duration-700`.
  - Задержка появления: увеличивай на 150–200 мс для каждой следующей карточки (чтобы они появлялись по очереди).
- Реализуй через компонент `motion.div` с `initial`, `animate`, `whileInView` и `viewport={{ once: true }}`.

## Адаптивность и мобильная логика
- Mobile (<768px): 1 колонка, карточка на всю ширину.
- Desktop: 3 колонки, достаточные отступы.
- Мобильная логика (тап = переход):
  - На мобильных устройствах при тапе на карточку должен происходить переход по ссылке без лишних визуальных эффектов (например, без `box-shadow` или `scale`).
  - Реализуй это через условные классы:
    - Desktop: `hover:border-cyan-400/60 hover:shadow-[0_0_24px_rgba(85,239,255,0.15)]`.
    - Mobile: `hover:none` или `active:scale-100` (чтобы убрать любые ховер‑эффекты на тач‑устройствах).
  - Убедись, что клик/тап по любой части карточки (включая бейдж, заголовок, описание, кнопку) приводит к переходу по ссылке.
  - Избегай вложенных ссылок (внутри карточки не должно быть других тегов `a`).

## Критерии приёмки
- Все 3 проекта перенесены с оригинальными описаниями.
- Кнопки в едином неоновом стиле.
- У каждой карточки есть неоновая рамка при наведении и мягкое циановое свечение.
- Вся карточка — кликабельная область, ведёт на указанный URL.
- Бейджи в едином сером стиле, при наведении — циановое свечение и текст `cyan-400`.
- При скролле карточки появляются по очереди с простой анимацией.
- На мобильных устройствах тап по карточке сразу приводит к переходу без лишних визуальных эффектов.
- Дизайн соответствует теме: тёмный фон, эффект стекла, минимализм.
- Нет ошибок в консоли, верстка не «едет» на мобильных.
- Используются семантические теги (`section`, `h2`, `p`, `a`).
